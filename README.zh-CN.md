# Science Stats Lab

为 Garcia 夏季科研项目（石溪大学）开发的实验室数据分析工具。粘贴仪器读数，立即得到溶胀比计算、不确定度统计和可直接进报告的图表——把一下午的表格折磨变成几次点击。

**在线体验：** [science-stats.vercel.app](https://science-stats.vercel.app)

**[English](README.md)** | **中文**

## 功能

- 🧪 **溶胀比计算**——水凝胶表征实验
- 📊 **不确定度统计**——均值、标准差、置信区间一目了然
- 📈 **报告级图表**——干净的可视化，直接放进实验报告

## 技术栈

- React + TypeScript + Vite

## 开发

```bash
npm install
npm run dev
npm run build
```
